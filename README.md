# Taiwo Bamgboye — Portfolio

Personal portfolio site for Taiwo Bamgboye, showcasing software engineering, academic, and electrical engineering work.

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Framer Motion
- React Router DOM

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
